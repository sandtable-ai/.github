# Contributing to sandtable-ai

Thanks for helping. These defaults apply to every repository in this organization that doesn't have its own.

- **Code, docs and examples** live in [sandtable-ai/sandtable](https://github.com/sandtable-ai/sandtable). Its [contributing guide](https://github.com/sandtable-ai/sandtable/blob/main/CONTRIBUTING.md) explains how issues and pull requests work there.
- **Published results** live in [sandtable-ai/leaderboard](https://github.com/sandtable-ai/leaderboard). Every file there is produced by `sandtable leaderboard`, so don't edit results by hand. If you think a verdict is wrong, open an issue in [sandtable-ai/sandtable](https://github.com/sandtable-ai/sandtable/issues), where the grading rules live, and link the trial. For a problem with the published data itself, such as a broken link or a missing file, open an issue in the leaderboard repository.
- **Questions** go to [Discussions](https://github.com/sandtable-ai/sandtable/discussions).

Everyone who takes part follows the [Code of Conduct](CODE_OF_CONDUCT.md).
